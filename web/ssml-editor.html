Instructions

Shape your narration with SSML

Speech Synthesis Markup Language (SSML) adds instructions around your text to control its spoken delivery. This editor is useful when a pause belongs inside a sentence or a particular phrase needs a different pace. For controls without markup, use the main TTS Tool.

Start with a short example

Choose a voice to open the editor. It inserts a speak wrapper with that voice's language. Keep the wrapper and place your text inside it. For an English (United States) voice, try:

<speak version="1.0" xml:lang="en-US">
  Welcome to the workshop.
  <break time="750ms"/>
  <prosody rate="slow">Take your time with this step.</prosody>
</speak>

The break requests three-quarters of a second of silence. The prosody tag asks the voice to read only the enclosed sentence more slowly. Keep the language generated for your chosen voice when adapting this example to another language.

Preview and save the result

Click Play to listen, then change one instruction at a time. Download opens the generated audio in a new tab; depending on your browser, use the audio player's menu to save it. If no tab opens, check whether your browser blocked the popup. Copy your markup into a local text file before leaving or reloading the page; this editor does not save it automatically.

Fix markup and voice errors

Every opening tag needs a matching closing tag, except self-closing tags such as <break time="750ms"/>. Use straight quotation marks around attributes. Write an ampersand as &amp; in XML text. Keep all content inside one speak element.

The editor checks XML syntax before sending the request, but valid XML does not mean every speech instruction is supported. Amazon and Microsoft voices can support different SSML features. If an example fails, start with plain text inside the wrapper and add tags back one at a time. See the Amazon Polly supported tags or Microsoft speech markup documentation for provider-specific details.
